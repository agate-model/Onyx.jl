# Onyx.jl

A size-structured nitrogen–phytoplankton–zooplankton–detritus ecosystem model built with [Agate.jl](https://github.com/agate-model/Agate.jl).

Onyx provides the scientific definition, model construction, and recipe replay. Agate supplies the shared construction and compilation machinery.

## Usage

```julia
using Onyx

bgc = Onyx.construct()

bgc, recipe = Onyx.construct_plus_recipe()
replayed = Onyx.construct(recipe)
```

Size structure and parameter overrides follow the original model interface in Agate.jl.

## Development

Until Agate v0.17.0 is released, use Agate's merged `main` branch with the explicit-provider API. With the two repositories checked out side by side:

```julia
using Pkg
Pkg.activate(".")
Pkg.develop(path="../Agate.jl")
Pkg.test()
```

The release will specify Agate v0.17 compatibility once v0.17.0 is tagged. The committed reference trajectory, originally generated by Agate.jl's NiPiZD implementation, is retained for numerical regression testing; regenerate it with `julia --project=. scripts/generate_onyx_reference.jl` when intentionally updating the scientific model.

The full tutorial collection remains in the [Agate documentation](https://agate-model.github.io/Agate.jl/dev/).
